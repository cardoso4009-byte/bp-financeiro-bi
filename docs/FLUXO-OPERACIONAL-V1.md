# Fluxo Operacional V1

**Entrada → Tratamento → Validação → Gestão → Fechamento**

1. **Entrada:** dados contábeis e financeiros por competência.
2. **Tratamento:** Financial Core consolida os dados e regras.
3. **Validação:** DRE, BP, DFC e DMPL são reconciliados.
4. **Gestão:** Visão Executiva, indicadores, capital de giro e alertas apoiam a decisão.
5. **Fechamento:** pendências são verificadas antes da conclusão da competência.

### Princípio de controle

Uma demonstração gerencial deve sempre permitir rastrear o número até sua origem e sua regra de cálculo. Reconciliações são controles, não mecanismos para mascarar divergências.
